# HOW Talk — GitHub Pages

## 업로드 방법
1. GitHub에서 새 repository를 만듭니다. 예: `how-talk`
2. 이 ZIP의 압축을 풉니다.
3. `index.html`과 `media` 폴더를 repository 최상위(root)에 업로드합니다.
4. GitHub repository → **Settings → Pages**
5. **Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
   - Save
6. 잠시 후 GitHub Pages 주소가 생성됩니다.

예상 주소:
`https://YOUR-USERNAME.github.io/how-talk/`

## 발표 조작
- → / Space : 다음
- ← : 이전
- F : 전체화면
- N : 발표자 노트
- 스마트폰: 좌우 스와이프

## 현재 영상
- 중국 영상: `media/china.mp4`
- 미국/한국 영상은 아직 placeholder입니다.

나중에 미국/한국 영상도 같은 `media` 폴더에 넣고 HTML에 연결하면 됩니다.
